## next@14.2.35 — 23 open advisories (representative sample)

All require a major version bump (fixed in 15.5.x / 16.x lines):

- GHSA-2xp9-vwfh-vxw4 — Unauthenticated RCE in Image Optimization API (AVIF)
- GHSA-p293-qw3h-jr36 — Unauthenticated RCE on Windows-hosted servers
- GHSA-89xv-2m56-2m9x — SSRF in Server Actions on custom servers
- GHSA-955p-x3mx-jcvp — Unauthenticated disclosure of internal Server Function endpoints
- GHSA-p9j2-gv94-2wf4 — SSRF in rewrites via attacker-controlled destination
- GHSA-c4j6-fc7j-m34r — SSRF via WebSocket upgrades
- GHSA-ffhc-5mcf-pf4q / GHSA-gx5p-jg67-6x7h — XSS (CSP nonces / beforeInteractive)
- GHSA-3x4c-7xq6-9pq8 — Unbounded next/image disk cache growth
- Plus cache-poisoning / DoS / middleware-bypass advisories (full list in OSV).

**Decision: DEFERRED, not fixed.** Upgrading Next.js 14 → 15/16 is a major
migration (App Router behavior changes, dependency compatibility with
@xyflow/react, React version). Per policy (“fix only safe upgrades, don't
break the build”), this is documented rather than attempted mid-phase.
**Recommended follow-up:** schedule a Next.js 15/16 upgrade as its own
workstream with the full test suite + production build + smoke test as the
gate. Until then, mitigate by: keeping the app behind HTTPS, not exposing the
dev server publicly, and avoiding AVIF remotePatterns in next/image config.

## Update — 2026-10-19: Next.js 14.2.35 → 15.5.28 (major bump)

JOE approved the major upgrade to close the 23 open advisories on next@14.

**Method:** same OSV.dev `querybatch` approach (`npm audit` remains blocked by
sandbox policy).

**Results after the bump:**

| Package | Installed | Open advisories |
|---|---|---|
| **next** | **15.5.28** | **0** (all 23 resolved, incl. GHSA-2xp9-vwfh-vxw4 and GHSA-p293-qw3h-jr36) |
| react / react-dom | 18.3.1 (unchanged — Next 15 supports React 18) | 0 |
| @prisma/client, @xyflow/react, bcryptjs, jsonwebtoken, lucide-react, recharts, zod | unchanged | 0 |
| vitest | 2.1.9 (unchanged, dev-only) | 2 (unchanged — GHSA-5xrq-8626-4rwp, GHSA-82fw-gwwq-j7x9; still deferred, test-runner only) |

**Migration work (all in-repo, no data touched):**

- `package.json`: `"next": "^15.5.28"` (was `^14.2.18`). No React/recharts
  upgrade — Next 15 supports React 18.
- **Async `params`**: 51 API route files migrated — type
  `{ params: { id: string } }` → `{ params: Promise<{ id: string }> }`,
  usages `params.id` → `(await params).id` (same for `provider`, `orderId`
  shapes). The official `@next/codemod` transform could not write in this
  environment (jscodeshift EPERM on chown, 0 files changed), so the migration
  was done with a reviewed script + manual review of every file.
- **Async `cookies()`/`headers()`**: `src/lib/auth.ts` (`getSession`,
  `setSessionCookie`, `clearSessionCookie`), `src/lib/tenancy.ts`
  (`setWorkspaceCookie`), `src/app/api/auth/login/route.ts`,
  `src/i18n/server.ts` (`getLocale()` now async); all callers updated
  (30 `getLocale()` call sites, 8 server components made async).
- **Client pages**: `src/app/app/automations/[id]/page.tsx` and
  `[id]/executions/page.tsx` unwrap `params` with React `use()`.
- `src/middleware.ts`: unchanged (fine on 15; `proxy.ts` rename is a 16
  convention — not adopted).

**641/641 tests pass (56 files)** · `npm run build` 103/103 pages ·
